# Humanitní rešerše se stopou zdrojů

Student připraví rešeršní protokol, podle něhož může ověřit zdroj každého podstatného tvrzení. Pro VŠ, zejména pro humanitní předměty.

## Jak použít prompt

1. Otevřete [český prompt](cs/humanitni-reserse-zdroje.md) a vložte jeho obsah jako první zprávu do chatu.
2. Doplňte otázku, období a území, jazyky pramenů, zadaný korpus nebo souhlas s webovou rešerší a rozsah práce.
3. Projděte návrh a upravte dokument. Stažitelný DOCX závisí na nástrojích chatu. Náhradní výstup je Markdown pro textový editor.

## Příklad

Jak dva regionální deníky rámovaly tutéž stávku? Vymez období, jazyk a korpus, včetně čísel, která se nepodařilo dohledat.

## Stav a soukromí

První vydání. Chování v konkrétních modelech ani tvorba příloh zatím nemají doložený test. Repozitář obsahuje textový postup. Podklady zpracovává poskytovatel zvoleného chatu. Používejte veřejné nebo anonymizované materiály.
