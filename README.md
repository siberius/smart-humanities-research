# Humanities Research with a Source Trail

The student builds a research log they can use to verify the source of each material claim. For university humanities work.

## How to use

1. Open the [English prompt](en/humanities-research.md) and paste it into a new chat.
2. Provide the question, period and place, source languages, a supplied corpus or permission to search the web, and scope.
3. Review the draft and edit the document. Downloadable DOCX depends on the chat's file tools. The fallback is Markdown for a word processor.

## Example

How did two regional newspapers frame a strike? Define the period, language and corpus, including issues you could not locate.

## Status and privacy

First release. Model behaviour and file generation have no documented test yet. The repository contains a written workflow. The chosen chat provider handles your materials. Use public or anonymised sources.
